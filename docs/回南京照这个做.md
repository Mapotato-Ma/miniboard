# 回南京后照这个做

> 目标：把 ipa 装到手机上，回答一个问题 —— **自己签名的 App 能不能出组件？能不能拿到 iOS 27 的 4×6 超大组件？**
>
> 预计 30 分钟。卡住就把截图发给 Minis。

---

## 第 0 步：先确认一件事

**新 Apple ID 注册好了吗？** 没注册就去 <https://appleid.apple.com> 建一个（免费的，不用花 $99）。

- 国家/地区选**中国**就行 —— 我们走 AltStore，不需要换区
- 别用你的主力 Apple ID，用新注册这个

---

## 第 1 步：电脑（约 10 分钟）

- [ ] 装 **iTunes** 和 **iCloud**

  ⚠️ **必须从 Apple 官网下载，不要用 Microsoft Store 版**
  - iTunes：<https://www.apple.com/itunes/download/>（页面往下找 Windows 版）
  - iCloud：<https://support.apple.com/zh-cn/106488>
  - **装错了会怎样**：AltServer 完全认不到你的手机。这是最常见的翻车点，先排除它。

- [ ] 装 **AltServer**：<https://altstore.io> → Download → AltStore Classic

- [ ] 右键 AltServer → **以管理员身份运行**（Windows）

- [ ] 确认 iTunes / iCloud 正在运行（托盘里有图标）

---

## 第 2 步：手机换「媒体与购买项目」（1 分钟）

```
设置 → 顶部你的名字 → 媒体与购买项目 → 退出登录 → 用新 Apple ID 登录
```

⚠️ **只换这一个。千万不要去退出 iCloud。**
- iCloud（照片/备忘录/通讯录）→ 保持主力账号不动
- 媒体与购买项目（App Store）→ 换成新账号

换完桌面、照片什么都没变，只是 App Store 换了账号。

---

## 第 3 步：装 AltStore（5 分钟）

- [ ] USB 线连手机到电脑
- [ ] 手机上弹「信任此电脑」→ **信任**，输入锁屏密码
- [ ] 电脑托盘 AltServer 图标 → **Install AltStore** → 选你的设备
- [ ] 输入新 Apple ID（**注意区分大小写**）→ 会弹双重认证，手机收验证码填进去
- [ ] 手机上：设置 → 通用 → VPN 与设备管理 → **信任** 那个开发者描述文件
- [ ] 手机上：设置 → 隐私与安全性 → 拉到底 → 打开**开发者模式** → 重启手机
- [ ] 打开 AltStore，登录同一个 Apple ID

---

## 第 4 步：装我们的 App（2 分钟）

- [ ] 手机 **Safari** 打开（会自动存进「文件」App）：

  ```
  https://github.com/Mapotato-Ma/miniboard/releases/download/ipa-latest/MiniBoard.ipa
  ```

- [ ] 打开 **AltStore** → **My Apps** → 左上角 **+** → 选那个 ipa
- [ ] 等它签名安装完，桌面出现「**看板**」
- [ ] 第一次打开可能提示不受信任 → 设置 → 通用 → VPN 与设备管理 → 信任

---

## 第 5 步：验证（1 分钟，最关键）

- [ ] 长按桌面空白 → 左上角 **+** → 搜「看板」→ 拖一个组件出来
- [ ] **长按这个组件 → 抓住右下角的把手，往外拖**

看组件**左上角的角标**：

| 角标 | 结论 | 下一步 |
|---|---|---|
| **`extraLarge ★`** | 🎉 成了 | 告诉 Minis，开始往里填内容 |
| `large` | 只能到大号 | 截图给 Minis，查原因 |
| `small` / `medium` | 扩展没打进去 | 截图给 Minis |
| `unknown` | SDK 不对 | 截图给 Minis |

---

## 卡住了怎么办（常见报错对照）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| AltServer 找不到设备 | iTunes/iCloud 是 Microsoft Store 版 | 卸载，去 Apple 官网重装 |
| 同上 | 数据线是纯充电线 | 换一根能传数据的 |
| 同上 | 手机没点「信任」 | 拔了重插，注意手机弹窗 |
| `Maximum number of apps for free development profiles has been reached` | 免费账号 3 个上限 | 删掉一个别的侧载 App，或等下周一（App ID 每周重置 10 个） |
| 安装时提到 `appex` / `entitlement` / `application-identifier` | **免费账号签带扩展的包出问题** ← 这正是我们要验证的 | 截图给 Minis，这信息很有价值 |
| 7 天后 App 打不开了 | 证书过期 | 手机和电脑连**同一个 Wi-Fi**，电脑上 AltServer 开着，在 AltStore 里点 Refresh |
| 桌面搜不到「看板」组件 | 扩展还没被系统索引 | 先手动打开一次 App，再回桌面长按添加 |
| 拖不动把手 | 系统认为不支持超大组件 | 截图给 Minis |

---

## 成功之后

告诉 Minis「角标显示 extraLarge 了」，下一步就是把内容填进去：

1. 组件里跑 **JavaScriptCore**，执行一段 JS
2. 做 JS API（Stack / Text / Image…）映射到 SwiftUI
3. 把之前那个「今日看板」的设计搬进来，这次是**真正占满整屏**

改代码 → 推上去 → CI 自动出新 ipa（约 3–4 分钟）→ AltStore 重新导入一次即可。
